# C4-диаграммы

- [SystemContext.svg](SystemContext.svg) — система, пять ролей и внешние провайдеры.
- [Containers.svg](Containers.svg) — полная контейнерная диаграмма: Web Application, семь сервисов, шесть БД и внешние системы. Открывайте SVG отдельно и увеличивайте масштаб для чтения подписей.

Источник — [workspace.dsl](../workspace.dsl). JSON, DOT и SVG генерируются из него. В SVG сохранены границы системы, типы элементов, назначение, технологии и направления связей. DOT-экспортёр изображает людей прямоугольниками с меткой `[Person]`; интерактивный Structurizr использует фигуру человека.

## Условные обозначения

| Обозначение | Значение |
| --- | --- |
| Тёмно-синий элемент `[Person]` | Пользовательская роль |
| Синий элемент `[Container: ...]` | Приложение или микросервис |
| Цилиндр PostgreSQL | База данных единственного сервиса-владельца |
| Серый элемент `[Software System]` | Внешний провайдер |
| Сплошная стрелка | HTTP-вызов или SQL-доступ, инициатор → получатель |
| Светло-серая стрелка JWKS | Периодическое обновление публичных ключей; JWT проверяется локально |
| Оранжевая пунктирная стрелка `via RabbitMQ` | Асинхронное событие, издатель → потребитель, доставка через брокер |

Внешние провайдеры обозначены по ролям: конкретные продукты ещё не выбраны. Детали развёртывания и физический брокер не представлены; асинхронные зависимости показаны непосредственно между сервисами. Контракты стрелок описаны в [contracts.md](../contracts.md).

## Повторение проверки и экспорта

При подготовке использованы Structurizr DSL/Core/Export **5.0.1** из установленного Structurizr Lite **2025.11.08**, Java **23.0.1** и Graphviz **15.1.1**. Экспортёр запускает настоящий парсер DSL, а затем штатные JSON/DOT-экспортёры Structurizr; отдельной вручную поддерживаемой модели нет.

Нужны JDK, Graphviz (`dot`), `unzip` и файл `structurizr-lite.war` указанной версии. WAR можно взять из [официального дистрибутива](https://docs.structurizr.com/lite/installation) или скопировать из своего работающего контейнера:

```sh
docker cp <имя-контейнера>:/usr/local/structurizr-lite.war /tmp/structurizr-lite.war
```

Из корня репозитория:

```sh
export_libs=$(mktemp -d)
unzip -q /tmp/structurizr-lite.war 'WEB-INF/lib/*' -d "$export_libs"
java --class-path "$export_libs/WEB-INF/lib/*" tools/ExportWorkspace.java .
dot -Tsvg diagrams/SystemContext.dot -o diagrams/SystemContext.svg
dot -Tsvg diagrams/Containers.dot -o diagrams/Containers.svg
git diff --check
```

Успешный запуск сообщает `Parsed and exported` для обоих представлений. Ошибка DSL завершает программу до записи экспорта. Библиотеки остаются во временной папке и не добавляются в репозиторий. Для интерактивного просмотра см. [README](../README.md#просмотр-диаграмм).
